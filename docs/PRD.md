# 「소수의 음악」 — 리만 가설 A to Z 학습 앱 PRD (v0.1)

> Claude Code 핸드오프용 스펙. 이 파일을 레포 루트에 `docs/PRD.md`로 두고, 첫 세션에서 "PRD 읽고 CLAUDE.md + 프로젝트 스캐폴드 만들어줘"로 시작.

## 1. 목표
- 소수를 잊은 **일반 성인**이 리만 가설의 의미를 이야기 → 직관 → 수식 순으로 끝까지 이해하게 하는 독립 웹앱.
- 언어: **한국어 v1 → 영어 v2**. 처음부터 i18n 구조로 작성 (문자열·콘텐츠 하드코딩 금지).
- 이후 Manim 기반 유튜브 시리즈로 재활용 → 콘텐츠·수치 데이터는 앱/영상 공용 소스로 관리.

## 4. 핵심 인터랙션 스펙
1. **체**: 1~N 격자, 소수 클릭 시 배수 순차 제거. N 슬라이더.
2. **줌 그래프**: π(x), x/ln x, Li(x) 오버레이. x 범위 10~10⁹ 로그 줌. 오차 곡선 토글.
3. **복소평면**: 점 드래그, ×i 버튼(90° 회전 애니), e^{iθ} θ 슬라이더.
4. **제타 풍경**: WebGL 셰이더 도메인 컬러링, 영점 마커, 임계띠 하이라이트.
5. **제타 나선**: ζ(½+it) 궤적, t 슬라이더, 원점 통과 순간 하이라이트 + 효과음.
6. **명시공식 슬라이더** ⭐: 영점 K개(1→1000) 파동 합으로 소수 계단 재구성. 실시간 갱신.
7. **소리** ⭐: 영점 허수부 → 주파수 매핑(Web Audio). 영점 하나를 임계선 밖으로 드래그 시 진폭 증가로 소리 왜곡 = "가설이 틀린 세계".
8. **간격 통계**: 정규화된 영점 간격 히스토그램 + GUE Wigner surmise 곡선.

## 5. AI 튜터 원칙
- 정본은 **사전 작성 유도**. AI는 보조(질문 응답·재설명)만.
- 학습 원리: 소크라테스식 문답, 생성 효과(사용자가 먼저 예측/답하게), **AI는 힌트만, 정답은 사용자가**.
- Claude API 호출은 서버리스 함수(Vercel) 경유, 키 클라이언트 노출 금지.
- 콘텐츠 스키마를 과목 독립적으로 설계 → 범용 학습 시스템 코어로 재사용 가능하게.

## 6. 기술 스택
- React + Vite + TypeScript, 배포 Vercel
- 수식 KaTeX / 그래프 D3 + Canvas / 풍경 WebGL / 소리 Web Audio
- 콘텐츠: MDX 또는 JSON(스테이지 × 레이어 × 언어 × 에디션)
- i18n: react-i18next, `ko` 기본, `en` 슬롯
- 수치 데이터: Python(mpmath)로 영점·π(x) 사전 계산 → `public/data/*.json`
  - 영점 상위 1만 개 정도면 충분, 필요시 Odlyzko 공개 테이블
- 영상 재활용: 같은 JSON을 Manim 스크립트(`video/`)에서 읽도록
